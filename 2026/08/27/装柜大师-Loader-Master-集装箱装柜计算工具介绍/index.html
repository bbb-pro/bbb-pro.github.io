装柜大师 Loader Master —— 浏览器里的集装箱装柜计算工具

发表于2026-08-27|更新于2026-08-27|项目
|浏览量:

发货前心里没底：这柜子到底能装多少？怎么码最省空间？重心稳不稳？
装柜大师（Loader Master） 是一个单文件、零依赖的浏览器端集装箱装柜计算工具，帮你一键算出「怎么码、能装多少、重心稳不稳」，还能导出 PDF 作业单。

✨ 这是什么

装柜大师是一个纯前端的集装箱装载规划工具：无需后端、无需安装，双击 HTML 即可在任意现代浏览器运行。它适用于外贸、仓储、物流、拼柜等场景，帮你在发货前快速得到一份可落地的装柜方案。

  • 🌐 在线使用：https://057300.xyz/loader-master/

🚀 三步上手

  1. 选柜型：顶部下拉框选目标集装箱（默认 40HQ），内置 20GP / 40GP / 40HQ / 45HQ 四种标准内尺寸与限重。
  2. 加货物：点「＋ 添加货物」填尺寸、重量、数量，勾选托盘可看实时打托预览。
  3. 算方案：点「🚀 计算装柜」，立刻得到 3D 装柜图、汇总表、货物明细与告警提示，再一键导出 PDF / Excel。

📖 操作演示

① 选择柜型

在顶部「柜型」下拉框选择目标集装箱，默认 40HQ。内置标准集装箱尺寸如下（尺寸单位：米；限重单位：吨）：

柜型 内容积 (长×宽×高) 限重 容积
20GP 5.94 × 2.34 × 2.39 28.25 t 33 m³
40GP 12.06 × 2.34 × 2.39 28.8 t 67 m³
40HQ 12.06 × 2.34 × 2.69 30.2 t 76 m³
45HQ 13.58 × 2.35 × 2.69 * 27 t * — *

*45HQ 暂未提供标准数据源，数值沿用原预设仅供参考；20GP / 40GP / 40HQ 均采用标准集装箱公开数据。

② 添加并配置货物

点击「＋ 添加货物」新增卡片，逐项填写名称、长/宽/高、单重、数量、优先级、分组、最大上层承重等；勾选「托盘」并填托盘尺寸后，卡片底部会实时显示打托方案俯视图（SVG），标注「每托 X 箱 / Y 层 / 整托高 Z mm」。

③ 一键计算，查看 3D 方案

点「🚀 计算装柜」生成方案。左侧生成立体效果，可拖拽旋转 / 滚轮缩放 / 右键平移查看；点击任意箱子弹出底部浮层，可旋转 90° 或删除（删除后算法自动重排）。

④ 导出 PDF / Excel 作业单

将计算结果导出为中文 PDF 作业单（含汇总表、3D 示意图、货物明细、仓库作业说明，表格自适应字号避免重叠），或导出 Excel 明细；也支持下载导入模板批量录入。

🧰 功能特性一览

类别 说明
多柜型支持 内置 20GP / 40GP / 40HQ / 45HQ 四种标准集装箱内尺寸与限重
砖砌码盘算法 同形矩形托盘采用「砖砌式交错」布局，密度贴合人工摆放（40HQ + 1200×1000 托盘可达 22 托/层）
打托方案预览 勾选托盘后实时生成俯视打托图（SVG），直观核对每托箱数与交错方式
3D 可视化 Three.js 渲染装柜结果，可旋转 / 缩放 / 平移；点击箱子可旋转朝向或删除
摆放顺序 支持「从里到外」（柜里端优先）与「从外到里」（柜门端优先）两种策略
优先级调度 1/2/3 级优先级，优先货物置于柜内最里侧底层，靠门货物最后装入
理论容量估算 针对当前柜型估算单货最多可放数量与整托高度，发货前快速判断
Excel 互通 一键下载导入模板批量导入，结果可导出 Excel 明细
PDF 作业单 导出含汇总、3D 示意图、明细、作业说明的中文 PDF
零依赖离线 所有依赖通过 CDN importmap 加载，HTML 单文件即可分发，计算全程本地完成
移动端自适应 手机端自动切换为「上(设置) / 中(3D) / 下(结果)」垂直排版

🧠 算法亮点

  • 柜级砖砌码盘：一层内可放多个相同矩形托盘时，相邻行交替 90° 朝向，消除行列对齐空隙，密度与人工贴合摆放一致（典型：40HQ + 1200×1000 托盘 = 22 托/层）。
  • 托级打托：palletLevelLayout() 枚举砖砌行组合求每托每层最大箱数，供理论估算与 3D 渲染共用，保证「理论容量」与「实际渲染」严格一致。
  • 由内向外推进：先码第一托底层 → 隔壁交错第二托底层 → 第一托第二层 → 第二托第二层，依次向外推进，符合人工码盘习惯。
  • 优先级调度：按优先级排序填充，优先货物置柜里端底层，靠门货物最后装入，便于卸货顺序。

⚠️ 本工具为模拟估算，实际装柜请结合货物特性、捆扎方式、重心与运输要求现场确认。

🛠 技术栈

  • 前端框架：原生 HTML + Tailwind CSS（CDN）
  • 3D 渲染：Three.js（CDN importmap）
  • 表格处理：SheetJS（xlsx 导入导出）
  • PDF 生成：jsPDF + Canvas 栅格化（规避中文字体缺失）
  • 运行环境：纯浏览器端，无后端、无构建步骤
