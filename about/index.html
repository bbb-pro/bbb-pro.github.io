关于本站 / About

包装&物流工具箱（Packaging & Logistics Toolbox）是一个面向包装设计与物流测算场景的免费在线工具集，域名 057300.xyz。站点由独立开发者星辰月光酿大树维护，核心诉求只有一条：把日常最耗时的重复计算和绘图工作，做成打开即用的工具。

Packaging & Logistics Toolbox is a free, browser-based toolkit for packaging design and logistics planning, hosted at 057300.xyz. It is maintained by an independent developer. The goal is simple: turn repetitive calculations and drawing work into tools you can open and use immediately.

工具清单 / Tool list

工具 地址 用途
刀模设计 DieCut Designer /diecut/ 上千种标准纸盒刀模参数化生成、实时 2D 预览，导出 SVG / DXF / PDF，对接印刷打样。
装柜大师 Loader Master /loader-master/ 集装箱 3D 装柜仿真与装箱计算，输出 3D 码放方案、装载率与总重统计。
标签编辑器 Label Editor /label-editor/ 矢量条码标签设计，Code 128 / Code 39 / QR 支持，多对象编排、模板复用、PDF/PNG 导出、Excel 批量套打。
Markdown 编辑器 Lite MD Editor /lite_MD_editor/ 类 Word 的本地 Markdown 可视化编辑器，完全离线，支持 PDF 导出。

站点特点 / What makes it different

  • 免费、无需注册：四款工具均不设登录门槛，打开即用。
  • 数据不出浏览器：所有工具为纯前端实现，刀模图、标签文件、装柜方案与文档全部在本地处理，不上传服务器，敏感图纸可放心使用。
  • 导出即交付：直接输出行业通用格式（SVG / DXF / PDF / PNG / Excel），不需二次转换。
  • 离线可用：首次加载后可脱离网络继续工作。
  • 中英双语：导航栏提供「中 / EN」一键切换。

技术栈 / Tech stack

博客与站点框架为 Hexo 7 + Butterfly 主题；四款工具分别为原生前端单页应用，其中刀模设计内置上千种盒型参数模型，装柜大师采用 3D 装箱算法，标签编辑器基于 Canvas 矢量渲染，Markdown 编辑器为 Electron 桌面应用。站点托管于 GitHub Pages，前置 Cloudflare 代理。

The blog runs on Hexo 7 with the Butterfly theme; all four tools are native front-end single-page applications. Hosting is GitHub Pages behind Cloudflare.
